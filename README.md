# Суперпоиск · Зубарев смотрит

Статический сайт: https://krizof.github.io/zubarev-search/

Каталог читает новый канал **@zubarefffwatch**, ID **3785873801**. Приложение работает в обычном браузере и Telegram Web App. Сборщик и сервер для публикации не нужны.

## Возможности

Поиск по названию, актёрам, режиссёру и описанию; опечатки, раскладка и распространённые английские названия. Фильтры по типу, жанру, году, Кинопоиску и доступности. Пример: `комедия 90-е 7+`.

Каталог, жанры, топ, новые и недоступные записи используют один `catalog.json`. Неизвестные оценки не заменяются нулями. Диапазоны оценок сохраняются диапазонами. Закладки и тема хранятся только в браузере. Ссылку на карточку или результат поиска можно сохранить.

## Обновление истории

На этом компьютере запустить **Обновить_суперпоиск.bat**, либо:

```powershell
py -X utf8 scripts/update_catalog.py
```

Нужны Python с Telethon и существующий вход из соседнего проекта `ТГ_Загрузчик`. Путь можно изменить параметрами `--config` и `--session` у `scripts/fetch_channel.py`. Скрипт читает ключ сессии в память и не изменяет исходную сессию, сообщения или медиа. Учётные данные и полный технический снимок находятся вне публикуемых файлов. Не публиковать папку `.local` или `*.session`.

Обновление полностью читает историю и проверяет канал. При ошибке чтения, чужом канале, пустой истории или потере более 20% сообщений каталог не перезаписывается. Известные удалённые записи сохраняются с причиной. Слова Telegram про copyright означают ограничение Telegram, а не установленную нами дату удаления. Проверяется наличие видео в сообщениях; воспроизведение каждого байта видео не проверяется.

Если не удалось распознать длинное видео, оно попадает в `catalog.json → review` для проверки. `metadata-overrides.json` хранит проверенные связи двух альтернативных записей с исходными фильмами.

После обновления:

```powershell
py -m unittest discover -s tests -p "test_*.py"
node --test tests/search.test.cjs
git add .
git commit -m "Refresh Telegram catalogue"
git push origin main
```

GitHub Pages публикует ветку `main`, корень репозитория. Кнопка «Проверить обновление» на сайте загружает опубликованный каталог; она не запускает сканирование Telegram. Фонового расписания нет.

## Локальная проверка

```powershell
py -m http.server 8765 --bind 127.0.0.1
```

Открыть http://127.0.0.1:8765/. Через `file://` загрузка JSON браузером не поддерживается.

## Файлы

* `index.html`, `styles.css`, `app.js`: интерфейс, без внешних UI-зависимостей.
* `search.js`: независимый поисковый движок с тестами.
* `catalog.json`: единая опубликованная версия данных, дата проверки и изменения.
* `posts.json`, `genres.json`, `ratings.json`: совместимость со старой версией, генерируются из того же каталога.
* `scripts/fetch_channel.py`: только чтение Telegram.
* `scripts/build_catalog.py`: метаданные, статусы, сравнение версий и сохранение.

Точные полные подписи сохраняются как обычный текст. HTML из Telegram не исполняется, ссылки на старый канал не используются для переходов.
